# KONONOV — сайт, заказы и Telegram-бот

Готовый проект для публикации через GitHub в Netlify. В проект входят сайт,
приём заказов, чат поддержки, уведомления Telegram, база клиентов и заказов,
последовательная нумерация и управление администраторами.

## 1. Загрузите проект в GitHub

Создайте пустой репозиторий и загрузите **содержимое этой папки** в его корень.
Папки `public` и `netlify`, а также `package.json` и `netlify.toml` должны быть
видны в корне репозитория.

## 2. Подключите GitHub к Netlify

1. Netlify → **Add new project** → **Import an existing project**.
2. Выберите GitHub и репозиторий.
3. Build command оставьте пустой.
4. Publish directory: `public` (обычно Netlify подставит её автоматически).
5. Нажмите **Deploy**.

## 3. Добавьте секретные переменные

Netlify → **Project configuration** → **Environment variables**:

| Переменная | Что указать |
|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather |
| `PRIMARY_ADMIN_ID` | Ваш числовой Telegram ID |
| `TELEGRAM_WEBHOOK_SECRET` | Любая длинная случайная строка без пробелов |
| `SETUP_KEY` | Другая длинная случайная строка без пробелов |
| `ROBOKASSA_MERCHANT_LOGIN` | Идентификатор магазина, например `kononovhealth` |
| `ROBOKASSA_PASSWORD_1` | Пароль №1 из технических настроек Robokassa |
| `ROBOKASSA_PASSWORD_2` | Пароль №2 из технических настроек Robokassa |
| `ROBOKASSA_HASH_ALGORITHM` | `MD5` |
| `ROBOKASSA_TEST_MODE` | `true` для теста, затем `false` для настоящих оплат |

После сохранения переменных откройте **Deploys** → **Trigger deploy**.

Не добавляйте настоящие значения в `.env`, GitHub или исходный код.

## 4. Один раз подключите webhook

После публикации выполните, заменив адрес сайта и ключ:

```bash
curl -X POST "https://ВАШ-САЙТ.netlify.app/api/telegram/setup" \
  -H "Content-Type: application/json" \
  -d '{"setupKey":"ВАШ_SETUP_KEY"}'
```

В ответе должно быть `"ok":true`. Затем откройте своего бота в Telegram и
нажмите **Start**. Бот подтвердит подключение администратора.

Проверка сервера:

```text
https://ВАШ-САЙТ.netlify.app/api/health
```

Все четыре значения в ответе должны быть `true`.

## 5. Подключите Robokassa

В технических настройках магазина укажите:

- Result URL: `https://healthkononovv.netlify.app/api/payments/robokassa/result`, метод POST.
- Success URL: `https://healthkononovv.netlify.app/api/payments/robokassa/success`, метод GET.
- Fail URL: `https://healthkononovv.netlify.app/api/payments/robokassa/fail`, метод GET.
- Алгоритм хеша: MD5.

Пароли №1 и №2 храните только в Environment variables проекта Netlify.

## Что работает

- Заказы получают номера `K-000001`, `K-000002` и так далее.
- Клиенты получают номера `C-000001`, `C-000002`; повторный телефон не создаёт
  нового клиента.
- Telegram показывает клиента, выбранный набор, цену, адрес и доставку.
- Кнопки заказа меняют статус: принят, в работе, отправлен, отменён.
- Сообщения из сайта приходят администраторам в Telegram.
- Администратор нажимает **Ответить клиенту**, пишет следующее сообщение, и оно
  появляется в открытом чате на сайте.
- Клики по «Заказать» и открытие поддержки отправляют отдельные уведомления,
  но не чаще одного раза за 10 минут от одного посетителя.
- Данные сохраняются в Netlify Blobs и не исчезают при новой публикации сайта.
- В боте есть кнопка **«Клиенты»** и команда `/clients`: они показывают базу
  клиентов, контакты и историю заявок по каждому номеру телефона.

## Администраторы

Самый надёжный вариант:

1. Основной администратор отправляет боту `/invite`.
2. Бот создаёт одноразовую ссылку на 24 часа.
3. Новый администратор открывает ссылку и нажимает **Start**.

Также доступны команды:

```text
/addadmin 123456789
/removeadmin 123456789
/admins
/clients
/help
```

Если добавить человека только по ID, Telegram может запретить боту первым
написать ему. В этом случае бот сообщит об этом. Человеку нужно самостоятельно
открыть бота и нажать Start либо воспользоваться приглашением `/invite`.

## Важное ограничение чата

Ответ администратора появляется у клиента, пока страница с открытым чатом
работает. История сохраняется. Для уведомлений покупателю после закрытия сайта
позже можно добавить SMS, email или отдельного клиентского Telegram-бота.
